      01 — The part nobody expects

      A text program you can use with the mouse.

      Click the record to pause it. Drag the waveform to seek. Click a row once to select it and again to play it, right-click to queue it. Roll the wheel over the list.

      Every colour, every toggle, every slider on the settings screen is clickable too. There is no configuration file to open unless you want to. The keyboard does all of it as well, and ? puts both on screen.

      5.5MB

      One executable. That is the whole install.

      0codecs

      to install. MP3 to AIFF, decoded natively in Rust.

      8formats

      MP3 · FLAC · WAV · OGG · Opus · M4A · AAC · AIFF

      −18LUFS

      EBU R 128 levelling. Each track measured once, then never too loud again.

      12second crossfade

      Gapless by default. The output device opens once and stays open.

      3systems

      Windows, Linux, macOS. Built by CI from the tag, with SHA256SUMS.

      02 — Sound

      Ten bands. Flat is bypassed, not computed.

      31 Hz to 16 kHz at ±12 dB, with the seven presets the player ships with. Drag a band, or focus it and use the arrow keys, exactly as you would in the terminal.

      03 — Everything else

      i. On screen

      • Album art in colour, from the embedded cover or a cover.jpg beside it. Real pixels in Windows Terminal, kitty, WezTerm, Ghostty, foot and xterm.
      • Lyrics with the current word lit, from a .lrc file or LRCLIB, shiftable per track.
      • Live FFT spectrum, a braille waveform of the whole track, a reactive sphere.
      • English and Turkish, switched without restarting.

      ii. Your library

      • Folders and m3u, m3u8, pls playlists are equally valid roots.
      • Titles from the tags, cached by size and time, so a large library pays once.
      • Queue, shuffle, repeat, filters, and five sort orders including by album.
      • w writes what you built as an m3u8 with relative paths. l likes, v cycles liked, most played, recent.

      iii. Outside the window

      • Media keys work while the terminal is in the background.
      • Survives an unplugged headset: it reopens the device and keeps going.
      • A sleep timer, and a window title that says what is playing.
      • Online search, streaming and downloads when yt-dlp is on PATH.

      05 — Install

      Three minutes.

      On Windows, scoop does the whole thing:

      scoop bucket add tlk https://github.com/Talkdedsec/scoop-tlk
scoop install tlk/tlk-tune
      1. Take the build for your system. Windows is where it has lived longest; Linux and macOS are newer and less travelled.
      2. Run it. With nothing configured it scans your Music and Downloads folders, so there is usually something to play straight away.
      3. ? shows every key and gesture. s opens the settings; the PATHS tab points it at the folder your music really lives in.
      Windowsx86_64 · .exe Linuxx86_64 macOSApple silicon SHA256SUMScheck a download

      Optional. It runs from wherever it sits; this puts it on your PATH as tlk-tune and tune, and adds “Play with tlk-tune” to the right-click menu of audio files. No administrator rights, and --uninstall takes every part back out.

      tlk-tune.exe --install

      Rust 1.88 or newer, and on Linux the ALSA headers (libasound2-dev).

      git clone https://github.com/Talkdedsec/tlk-tune.git
cd tlk-tune
cargo build --release

      Nothing is written outside %APPDATA%\tlk-tune and %LOCALAPPDATA%\tlk-tune until you ask for it.
